# React Image Gallery App

A responsive image gallery app built using React, Axios, and Tailwind CSS.  
This project fetches images dynamically from the Picsum API and displays them in a responsive grid layout.

---

## Features

- Responsive Design
- Dynamic API Fetching
- Pagination (Next & Prev Buttons)
- Tailwind CSS Styling
- React Hooks
- Mobile Friendly Layout

---

## Technologies Used

- React JS
- Axios
- Tailwind CSS
- Picsum API
